# thinksophia.app

frontend and root as well as brand main web presence and frontend ui for server container and applications

**ThinkSophia — Naturally Wise.** A minimalist, SwiftUI-style marketing site built with React, Vite, and plain CSS. It presents the ThinkSophia AI system and SaaS framework: SophiaLLM, Dyadic Social Fabric, the Beethoven Conductor Suite (Beethoven MCP, Beethoven Symphony, Beethoven ML, Beethoven Harmonizer Framework), and the Ubuntu-based SophiaOS platform (SophiaOS, SophiaWorks, Sophia Apps, and Sophia Ontology).

## Getting started

```bash
npm install
npm run dev       # local dev server
npm run build     # production build to dist/
npm run preview   # serve the production build locally
```
